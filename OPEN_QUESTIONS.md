# Open Questions

- How should a system represent a human state that changes continuously?
- How should predictions account for interventions that can alter their own target state?
- Where should epistemic state end and inference begin?
- How should intervention effects be attributed?
- How should uncertainty propagate through intervention and consequence?
- How should human agency constrain autonomous intervention?
- What does a correct prediction mean when the prediction itself can change behavior?
- What architectural primitives are required for state-active intelligence?
