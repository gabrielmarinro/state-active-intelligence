# Intervention

An intervention is an action that can change what happens next.

That creates a fundamental difference between analyzing a passive system and operating inside a system that can respond.

If intelligence recommends an action and that action changes the person's behavior, the next observation is partly a consequence of the intelligence itself.

The question is therefore:

> **How should intelligence reason about an outcome when its own action may have helped create that outcome?**

The public repository discusses the problem without publishing intervention logic or operational criteria.
