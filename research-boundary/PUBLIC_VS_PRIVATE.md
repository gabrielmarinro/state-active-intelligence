# Public vs Private

This repository exposes the research direction while protecting implementation-specific IP.

## Public

- Problem framing
- Core thesis
- Conceptual distinctions
- Design principles
- Thought experiments
- Comparative reasoning
- Open research questions

## Private

- Implementation
- Formal schemas
- Internal ontologies
- State and policy mechanics
- Inference mechanisms
- Decision mechanics
- Safety and governance mechanics
- Proprietary tests
- Operational architecture

**The implementation stays private. The thinking is public.**
